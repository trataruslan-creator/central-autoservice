# Быстрый старт: Развертывание на Hostland.ru

## Шаг 1: Сборка проекта

```bash
npm install
npm run build
```

После выполнения в папке `dist/` будут готовые файлы для загрузки на хостинг.

## Шаг 2: Загрузка на Hostland

### Вариант А: Через файловый менеджер (проще)

1. Войдите в панель управления Hostland: https://cp.hostland.ru/
2. Откройте **Файловый менеджер**
3. Перейдите в папку `public_html/` (или `www/`)
4. Удалите все старые файлы (если есть)
5. Нажмите **Загрузить** и выберите **все файлы** из папки `dist/`:
   - `index.html`
   - `.htaccess`
   - папку `assets/` со всем содержимым
6. Дождитесь завершения загрузки

### Вариант Б: Через FTP (FileZilla)

1. Скачайте [FileZilla](https://filezilla-project.org/)
2. Подключитесь к хостингу:
   - Хост: `ftp.ваш-домен.ru`
   - Логин: ваш FTP-логин (из панели Hostland)
   - Пароль: ваш FTP-пароль
   - Порт: 21
3. В правой панели перейдите в `public_html/`
4. В левой панели откройте папку `dist/`
5. Перетащите **все файлы** из `dist/` на сервер
6. Дождитесь завершения загрузки

## Шаг 3: Проверка

1. Откройте ваш домен в браузере
2. Сайт должен загрузиться
3. Проверьте все страницы:
   - Главная
   - Услуги и цены (#/uslugi)
   - Почему мы (#/preimushchestva)
   - Контакты (#/kontakty)

## Шаг 4: Настройка SSL (опционально)

1. В панели Hostland: **SSL-сертификаты** → **Заказать бесплатный сертификат**
2. Выберите ваш домен
3. Дождитесь выпуска (5-15 минут)
4. Включите **Принудительный HTTPS** в настройках домена

## Готово!

Сайт развернут и работает.

---

## Обновление сайта

Когда нужно обновить сайт:

```bash
npm run build
```

Затем загрузите новые файлы из `dist/` на хостинг тем же способом.

---

## Структура файлов на сервере

После загрузки структура должна быть такой:

```
public_html/
├── index.html          ← главная страница
├── .htaccess           ← настройки Apache
└── assets/
    ├── index-xxxxx.js  ← JavaScript
    └── index-xxxxx.css ← стили
```

**Важно:** загружайте только содержимое папки `dist/`, а не саму папку!

---

## Если что-то не работает

1. **Белый экран** — проверьте, что загрузили все файлы из `dist/`
2. **Ошибка 404** — убедитесь, что `index.html` находится в корне `public_html/`
3. **Не работают стили** — проверьте, что папка `assets/` загружена полностью
