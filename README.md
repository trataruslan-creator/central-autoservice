# Автосервис «Центральный» — сайт

Одностраничный многораздельный сайт автосервиса «Центральный» (Истра, д. Высоково, ул. Центральная, 13).
Позиционирование: **«качество официального дилера по цене гаражного сервиса»**.

## Возможности

- **Главная** — живое табло ремзоны (статусы работ обновляются в реальном времени), калькулятор стоимости
  «на глазок», прайс-ведомость популярных услуг, сравнение «дилер vs гараж vs „Центральный“»,
  спецпредложения, отзывы, партнёры.
- **Услуги и цены** (`#/uslugi`) — 14 услуг с поиском и фильтрами по 8 категориям, раскрывающиеся строки прайса,
  калькулятор, FAQ.
- **Почему мы** (`#/preimushchestva`) — процесс визита по шагам, оборудование (стенд сход-развала 3D, 2024 г.),
  видеонаблюдение ремзоны, гарантия, условия для юрлиц.
- **Контакты** (`#/kontakty`) — живой статус «открыто/закрыто» по расписанию, часы работы с подсветкой текущего дня,
  стилизованная карта со схемой проезда и ссылкой на Яндекс Карты, форма записи.
- **Запись на сервис** — глобальная модалка, открывается с любой кнопки сайта; выбранная услуга подставляется
  автоматически; валидация полей и экран успеха с номером заявки.
- **Мобильная версия** — нижняя панель действий «Позвонить / WhatsApp / Записаться», адаптивные сетки,
  меню-бургер, учёт safe-area.

## Технологии

- [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [React Router](https://reactrouter.com/) (HashRouter — работает на любом статическом хостинге без настройки)
- Шрифты: Oswald (заголовки) + Manrope (текст) + JetBrains Mono (технические подписи)
- Анимации: scroll-reveal, line-mask, scramble-декодирование, canvas-фон с пылинками, Ken Burns,
  бегущие строки; всё уважает `prefers-reduced-motion`.

```
src/

│   ├── JobBoard.tsx  # живое табло ремзоны

│   ├── Reveal.tsx    # анимации появления

│   ├── Home.tsx
```

## Запуск

```bash
npm install        # установить зависимости
npm run dev        # дев-сервер на http://localhost:5173
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр собранной версии
```

## Развёртывание

Проект собирается в статические файлы (`dist/`), поэтому подходит любой хостинг:
Netlify, Vercel, GitHub Pages, обычный nginx. Маршруты на HashRouter (`#/uslugi`),
поэтому дополнительная настройка rewrite-правил не требуется.

## WordPress-тема (основной продукт)

Проект переписан под самый универсальный движок — **WordPress** (текущий сайт central-autoservice.ru уже на нём).
Готовая тема лежит в папке [`wordpress-theme/central-autoservice/`](wordpress-theme/central-autoservice/README.md):

- установка: скопировать папку в `wp-content/themes/` → активировать → создать 3 страницы с шаблонами (`uslugi`, `preimushchestva`, `kontakty`);
- все данные (телефон, адрес, цены, отзывы, режим) редактируются в `functions.php` и `inc/data.php`;
- без jQuery, весь интерактив — нативный JS.
