# Тема «Центральный» для WordPress

Готовая тема сайта автосервиса «Центральный» (Истра, д. Высоково, ул. Центральная, 13).
Чистый PHP + нативный JS (без jQuery), адаптивная, уважает `prefers-reduced-motion`.

## Что внутри

- **Обложка при входе** — логотип, статус «открыто/закрыто», часы, адрес, кнопка «Показать на карте Яндекс»;
  оранжевая кнопка «В сервис» со штампом «ПОЕХАЛИ!» и плавным перелистыванием страницы (GPU-трансформация, без нагрузки).
- **Главная** — живое табло ремзоны, счётчики, бегущие марки, прайс, калькулятор, сравнение «дилер vs гараж»,
  предложения, прозрачность, отзывы, партнёры.
- **Услуги и цены** — 14 услуг, фильтры по категориям, поиск, раскрытие строк, FAQ.
- **Почему мы** — процесс визита, оборудование, видеонаблюдение, гарантия, юрлицам.
- **Контакты** — живой статус и часы (подсветка сегодняшнего дня), стилизованная карта со ссылкой на Яндекс Карты, форма записи.
- **Запись** — глобальная модалка, открывается с любой кнопки, услуга подставляется автоматически.

## Установка (3 шага)

1. Скопируйте папку `central-autoservice` в `wp-content/themes/` вашего сайта
   (через FTP/файл-менеджер хостинга или «Внешний вид → Темы → Добавить → Загрузить» в виде ZIP).
2. В админке: **Внешний вид → Темы → Активировать «Центральный»**.
3. Создайте страницы и привяжите шаблоны:
   - «Услуги и цены», ярлык `uslugi` → шаблон **Услуги и цены**;
   - «Почему мы», ярлык `preimushchestva` → шаблон **Почему мы**;
   - «Контакты», ярлык `kontakty` → шаблон **Контакты**.
   Настройки чтения менять не нужно: `front-page.php` работает автоматически на главной.

## Где менять данные

- **Телефон, WhatsApp, адрес, ссылка на карту** — константы в начале `functions.php`.
- **Услуги и цены, марки, отзывы, FAQ, сравнение, режим работы** — `inc/data.php`.
- **Изображения** — константы `APS_IMG_WORKSHOP`, `APS_IMG_ALIGNMENT` там же (или замените на URL из Медиабиблиотеки).
- **Цвета и шрифты** — переменные в начале `style.css`.

## Формы

Сейчас формы работают на клиенте (валидация + экран успеха). Чтобы заявки приходили на почту/в CRM,
подключите Contact Form 7 или свой обработчик `admin-ajax.php` — разметка форм находится в `footer.php` (модалка)
и `tpl-kontakty.php`.
