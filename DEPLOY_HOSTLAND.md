# Развертывание на Hostland.ru

## Подготовка проекта

### 1. Сборка проекта

Перед загрузкой на хостинг необходимо собрать проект:

```bash
npm install
npm run build
```

После выполнения команды в папке проекта появится папка `dist/` со статическими файлами:
- `index.html` — главная страница
- `assets/` — CSS, JavaScript и изображения

### 2. Проверка локально

Перед загрузкой можно проверить собранную версию:

```bash
npm run preview
```

Откройте http://localhost:4173 в браузере и убедитесь, что всё работает.

## Загрузка на Hostland.ru

### Способ 1: Через файловый менеджер (рекомендуется для небольших сайтов)

1. **Войдите в панель управления Hostland**
   - Перейдите на https://cp.hostland.ru/
   - Введите логин и пароль

2. **Откройте файловый менеджер**
   - В разделе "Хостинг" → "Файловый менеджер"
   - Перейдите в корневую папку вашего сайта (обычно `public_html/` или `www/`)

3. **Удалите старые файлы** (если есть)
   - Выделите все файлы и папки
   - Нажмите "Удалить"

4. **Загрузите файлы из папки dist/**
   - Нажмите "Загрузить"
   - Выберите **все файлы и папки** из локальной папки `dist/`
   - Дождитесь завершения загрузки

5. **Проверьте сайт**
   - Откройте ваш домен в браузере
   - Сайт должен работать

### Способ 2: Через FTP/SFTP (рекомендуется для частых обновлений)

#### Настройка FTP-клиента (FileZilla)

1. **Скачайте FileZilla**
   - https://filezilla-project.org/

2. **Получите данные для подключения**
   - В панели Hostland: "Хостинг" → "FTP-аккаунты"
   - Скопируйте:
     - Хост: `ftp.ваш-домен.ru` или IP-адрес
     - Логин: ваш FTP-логин
     - Пароль: ваш FTP-пароль
     - Порт: 21 (обычно)

3. **Подключитесь в FileZilla**
   - Файл → Менеджер сайтов → Новый сайт
   - Введите данные подключения
   - Нажмите "Соединиться"

4. **Загрузите файлы**
   - В правой панели (сервер) перейдите в `public_html/` или `www/`
   - В левой панели (локально) откройте папку `dist/`
   - Выделите **все файлы и папки** из `dist/`
   - Перетащите на сервер
   - Дождитесь завершения загрузки

## Настройка домена

### Если домен уже привязан к хостингу

Ничего делать не нужно — сайт сразу будет доступен по вашему домену.

### Если нужно привязать домен

1. В панели Hostland: "Домены" → "Добавить домен"
2. Введите ваш домен (например, `central-autoservice.ru`)
3. Укажите корневую папку (обычно `public_html/`)
4. Настройте DNS-записи у регистратора домена:
   - A-запись: IP-адрес хостинга (указан в панели Hostland)
   - Или NS-записи: ns1.hostland.ru, ns2.hostland.ru

## Установка SSL-сертификата (HTTPS)

### Бесплатный SSL от Let's Encrypt

1. В панели Hostland: "SSL-сертификаты" → "Заказать бесплатный сертификат"
2. Выберите ваш домен
3. Дождитесь выпуска сертификата (обычно 5-15 минут)
4. Включите "Принудительный HTTPS" в настройках домена

### Платный SSL

Если нужен расширенный сертификат:
1. "SSL-сертификаты" → "Заказать платный сертификат"
2. Выберите тип (Comodo, Symantec и т.д.)
3. Пройдите процедуру валидации
4. Установите сертификат на домен

## Обновление сайта

### Через файловый менеджер

1. Соберите новую версию: `npm run build`
2. В файловом менеджере Hostland удалите старые файлы из `public_html/`
3. Загрузите новые файлы из папки `dist/`

### Через FTP

1. Соберите новую версию: `npm run build`
2. В FileZilla удалите старые файлы на сервере
3. Загрузите новые файлы из папки `dist/`

## Решение проблем

### Сайт не открывается

1. **Проверьте, загружены ли файлы**
   - Убедитесь, что `index.html` находится в корне `public_html/`
   - Структура должна быть: `public_html/index.html`, `public_html/assets/...`

2. **Проверьте привязку домена**
   - Домен должен быть привязан к хостингу
   - DNS-записи должны быть настроены

3. **Очистите кэш браузера**
   - Ctrl+F5 (Windows) или Cmd+Shift+R (Mac)

### Ошибка 404 при переходе по страницам

Убедитесь, что загружены **все файлы** из папки `dist/`, включая:
- `index.html`
- Папку `assets/` со всеми файлами внутри

### Белый экран

1. Откройте консоль браузера (F12)
2. Проверьте ошибки JavaScript
3. Убедитесь, что все файлы загружены корректно

### Медленная загрузка

1. Включите сжатие Gzip в панели Hostland:
   - "Настройки" → "PHP" → "Включить gzip-сжатие"

2. Настройте кэширование через `.htaccess` (см. ниже)

## Оптимизация производительности

### Файл .htaccess

Создайте в корне сайта файл `.htaccess` со следующим содержимым:

```apache
# Включение сжатия
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/plain text/xml
    AddOutputFilterByType DEFLATE text/css text/javascript application/javascript
    AddOutputFilterByType DEFLATE application/json application/xml
</IfModule>

# Кэширование статики
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/jpg "access plus 1 year"
    ExpiresByType image/jpeg "access plus 1 year"
    ExpiresByType image/gif "access plus 1 year"
    ExpiresByType image/png "access plus 1 year"
    ExpiresByType image/svg+xml "access plus 1 year"
    ExpiresByType text/css "access plus 1 month"
    ExpiresByType application/javascript "access plus 1 month"
    ExpiresByType application/pdf "access plus 1 month"
    ExpiresByType application/x-javascript "access plus 1 month"
</IfModule>

# Защита системных файлов
<FilesMatch "^\.">
    Order allow,deny
    Deny from all
</FilesMatch>
```

## Структура файлов на сервере

После загрузки структура должна быть такой:

```
public_html/
├── index.html
└── assets/
    ├── index-[hash].css
    └── index-[hash].js
```

**НЕ** загружайте папку `src/`, `node_modules/` или другие исходные файлы — только содержимое `dist/`.

## Дополнительные возможности Hostland

В панели Hostland можно настроить автоматическое резервное копирование:

Если в будущем понадобится база данных:

- Тип: MySQL
- Данные для подключения будут в панели
