
### 2. WordPress-тема

**Файл:** `wordpress-theme/central-autoservice/functions.php`

**Функция:** `aps_yandex_verification()` (строки 50-54)

**Код:**
```php
/* Верификация Яндекс.Вебмастера */
function aps_yandex_verification() {
    echo '<meta name="yandex-verification" content="1f858cc5878868af" />' . "\n";
}
add_action('wp_head', 'aps_yandex_verification');
```

Мета-тег автоматически выводится в `<head>` на всех страницах WordPress-темы.

## Как проверить верификацию

### Быстрая проверка

1. Откройте ваш сайт в браузере
2. Нажмите **Ctrl+U** (просмотр исходного кода)
3. Найдите строку: `<meta name="yandex-verification" content="1f858cc5878868af" />`
4. Мета-тег должен быть в секции `<head>`

### Полная проверка в Яндекс.Вебмастере

1. Войдите в [Яндекс.Вебмастер](https://webmaster.yandex.ru/)
2. Добавьте сайт (если ещё не добавлен):
   - Нажмите "Добавить сайт"
   - Введите URL: `https://central-autoservice.ru`
   - Нажмите "Добавить"
3. Выберите способ верификации: **"Мета-тег"**
4. Нажмите **"Проверить"**
5. Если всё правильно, статус сайта изменится на "Зелёный"

**Подробная инструкция:** [YANDEX_VERIFICATION.md](YANDEX_VERIFICATION.md)
